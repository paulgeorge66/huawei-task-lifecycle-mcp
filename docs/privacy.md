# 隐私与数据流

这是自建软件，不是由本仓库维护者运营的公共云服务。部署者负责告知用户、限制访问、配置留存并遵守适用法律和组织政策。

## 数据流

```text
Agent / Hook / Skill
  → 你的 Cloudflare Worker
  → 你的 D1、KV 和 Queue
  → 华为动态消息接口
  → 关联的华为设备
```

服务不会把手机上的点击、回复、已读或展示状态传回 Agent；当前华为接口只提供请求接受结果。

## 会处理什么

- 任务标题、可见摘要、正文、结果、来源名称和项目标签；
- `task_id`、`run_id`、`event_id`、状态、进度、时间和 revision；
- 投递尝试、错误分类、华为业务码和诊断 trace；
- Agent 配置、Token 哈希/脱敏 hint 以及 OAuth 授权状态。

发送到华为的字段包括卡片标题、摘要、结果、正文、来源、显示时间，以及服务端派生的卡片/消息标识。原始 Agent Token 不会发送给华为。

## 不应处理什么

不要把以下内容放入标题、摘要或正文：

- 密码、验证码、OAuth code、Token、API key、华为授权码；
- 模型隐藏推理、系统提示或私有环境变量；
- 不适合出现在负一屏或锁屏提醒中的医疗、财务、身份、位置或第三方私密数据；
- 本地用户名、绝对路径、内部主机名或生产基础设施标识。

配套 Skill 会要求 Agent 对敏感任务使用最小化摘要，但模型指令不是数据防泄漏边界。部署者仍应限制任务来源、审查客户端权限并关闭不需要的通知内容。

## 存储和留存

D1 会保存事件、卡片投影和投递审计；Queue 会短期保存待处理消息；KV 保存 OAuth provider 状态；纯 Skill 与 Codex Hook 可能在本机权限为 `600` 的 outbox 中暂存未发送事件。

当前版本没有自动数据到期或面向终端用户的删除 API。需要留存策略的部署者应在公开使用前自行增加并验证清理流程。删除云端记录不会保证已显示的手机卡、日志副本、备份或历史通知同时消失。

## 凭据

- Cloudflare secrets 使用 Wrangler secret binding；
- Agent Token 只在创建/轮换时显示明文，服务端保存哈希和 hint；
- OAuth client secret、refresh token、管理员 cookie 和本地 `.env` 均视为秘密；
- 凭据疑似泄露时先轮换或撤销，再清理历史。
